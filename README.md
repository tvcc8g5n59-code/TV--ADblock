# TV--ADblock
TV Blocker runs dnsmasq in a Docker container and acts as your home DNS server. Lookups for ad, tracking and TV telemetry domains return 0.0.0.0, so the connections fail before they leave your network. A small web GUI lets you pause blocking, manage block and allow lists, and see which domains each device requests. Domains are scored from 1 to 10 for how likely they are to be ad or tracking traffic, using the bundled uBlock Origin domain list and name heuristics. Nothing is blocked automatically. You review and decide. The app uses only the Python standard library, so it needs no extra packages.
